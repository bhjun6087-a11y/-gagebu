# 차곡 · 간단한 가계부

모바일과 데스크톱에서 사용할 수 있는 한국어 가계부입니다. 수입·지출, 날짜, 카테고리, 메모를 입력하고 월별 합계와 내역을 확인할 수 있습니다. 내역 삭제와 유형별 필터를 지원합니다.

## 실행

별도 패키지 설치나 빌드가 필요하지 않습니다. 저장소에서 다음 명령을 실행하세요.

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

브라우저에서 서버의 3000번 포트로 접속합니다. 정적 웹 호스팅에도 배포할 수 있습니다.

## 데이터 저장

내역은 현재 브라우저의 localStorage에만 저장됩니다. 새로고침 후에도 유지되지만 브라우저 데이터 삭제 시 사라집니다. 기기 간 동기화나 계정 기능은 없습니다. 외부 글꼴을 불러오지 못해도 시스템 글꼴로 동작합니다.
